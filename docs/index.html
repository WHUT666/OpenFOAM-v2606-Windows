Why a native port?

为什么要做原生移植?

Upstream OpenFOAM supports Windows through WSL or MinGW-cross-compiled binaries. Neither gives you a real Windows development workflow.

OpenFOAM 官方在 Windows 上只有 WSL 或 MinGW 交叉编译包两条路,都给不了真正的 Windows 开发体验。

Quick start

快速开始

From release package to a running case in four commands.

从发行包到跑通案例,四条命令。

rem unpack OpenFOAM-v2606-Windows-x64.7z, then inside the package:
call setenv.bat
blockMesh -case tutorials\incompressible\icoFoam\cavity\cavity
icoFoam   -case tutorials\incompressible\icoFoam\cavity\cavity

rem MPI:
decomposePar -case <case> && mpiexec -n 4 icoFoam -case <case> -parallel

Building from source instead? See the Build guide. 想从源码构建?见 构建指南。

Verified workflows

已验证工作流

Everything below has actually run on this port — full list on the Testing page.

以下全部在本移植上实际跑过 —— 完整清单见 测试页。

  • foamToCcm ↔ ccmToFoam round-trip
