to first solve. 从压缩包
到第一个算例。 

rem unzip OpenFOAM-v2606-Windows-x64.7z, then:
call setenv.bat
blockMesh -case tutorials\incompressible\icoFoam\cavity\cavity
Mesh OK — 400 cells
icoFoam -case tutorials\incompressible\icoFoam\cavity\cavity
End
rem MPI — decompose, solve on N ranks, reconstruct:
decomposePar -case cavity
mpiexec -n 4 icoFoam -case cavity -parallel
reconstructPar -case cavity
